# 测试

所有命令从仓库根目录执行。测试需要 macOS；凭据后端直接依赖 macOS Security Framework。

## 自动化检查

```bash
npm ci
npm run check
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
npm run test:rust
```

前端测试覆盖连接注册时序、快速断线、重连失败保留历史、旧连接断线不污染新连接、关闭连接清理、异步目录 / 预览竞争、真实本地路径上传、取消文件对话框、传输互斥、设置保存失败、命令变量与路径校验。Rust 测试覆盖迁移、输入规范化、最近命令隔离、保留期与设置验证、完整主机密钥比较、替换旧指纹及文件路径边界。

## 真实协议集成测试

```bash
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
npm run test:integration
```

也可设置 `SSHEASY_TEST_PYTHON` 指向安装了依赖的 Python。默认 Rust 测试将这项标为 ignored，只有显式运行 `test:integration` 才会启动本地服务。

服务只监听 `127.0.0.1` 随机端口，生成一次性 Ed25519 主机密钥、加密用户密钥和临时目录。测试密码为固定夹具数据，不是实际服务器密码。结束后关闭服务并删除临时目录。

测试使用真实 russh 和 russh-sftp 网络请求，调用生产文件操作函数，包括错误密码、正确密码、加密 OpenSSH / 旧式 RSA PEM 私钥与错误口令、shell 输出、PTY / resize 请求、共享 SSH 上的 SFTP、中文预览、1 MiB 以上内容字节校验、已有文件拒绝、覆盖、失败下载保留旧文件、重命名冲突、嵌套目录及符号链接删除。

RSA 认证另覆盖两个互斥条件：现代服务端仅允许 SHA-256；旧式服务端不发送 `server-sig-algs` 扩展且仅接受 `ssh-rsa` 签名。两者都调用应用生产认证函数。测试夹具在实际验签前检查签名算法，不仅设置能力列表。

**覆盖边界：** 夹具接受 PTY 请求并运行真实 `/bin/sh` 子进程，不模拟完整系统登录环境，也不是实机交互程序兼容性测试。此项不打开 Tauri UI、不访问钥匙串、不经过生产指纹确认窗口；这些功能须在桌面手动验收。

## 桌面验收

仅使用你拥有且允许测试的服务器，文件修改使用可丢弃目录。

- 首次指纹拒绝 / 仅本次 / 保存，重连及真实指纹变化。
- 新建、编辑、测试和删除服务器；取消钥匙串授权的错误反馈；加密与未加密私钥。
- 浅色 / 深色主题、字体调整、设置重启持久化、拖动面板、最小窗口尺寸。
- 多服务器终端、切换历史、复制粘贴、搜索、退出 shell、主动关闭、断网和重连。
- 文件浏览、文本预览搜索、新建目录、上传、下载、同名覆盖取消 / 确认、重命名冲突和删除确认。
- 快捷命令变量、危险命令确认、最近命令隔离、书签跳转、日志过滤与实际 JSON 导出。

不要以通过构建替代真实服务验收，也不要把所有远端 Linux 工具的兼容性等同于 SSH 连接可用。CI 配置存在不代表远程 CI 已通过，应检查实际工作流结果。
